Mapping Urban Heat and Tree Canopy in Edinburgh

ArcPy Machine Learning Spatial Analysis

This project mapped urban heat across Edinburgh and tested whether council-managed tree data improved random-forest temperature prediction beyond an environmental baseline. Improved model preformance would indicate that tree cover is a relavent predictor of land surface temperature.

Tools and techniques: ArcGIS Pro, ArcPy, Forest-based regression, Spatial data management.

Data and methods

Council-managed trees were combined with NDVI and NDMI calculated from Sentinel-2 imagary, Landsat 9 land surface temperature, Copernicus elevation data and Edinburgh greenspace location data. Variables were aggregated to 6,500+ four-hectare hexagons using ArcPy. Forest-based regression models compared an environmental baseline of NDVI, NDMI, elevation and greenspace area with models including tree density, canopy coverage and maturity.

Results

The baseline model explained 72.0% of temperature variation. Adding tree density alone reduced performance, while adding canopy cover and maturity produced the highest validation R-squared of 0.726. Elevation, NDMI and NDVI remained the strongest predictors. Canopy coverage added modest predictive value and was more informative than tree density or maturity.

Data credits: City of Edinburgh Council Open Spatial Data Portal: Trees, Greenspace; USGS: Landsat 9 Surface Temperature; Copernicus: Sentinel-2 Imagery, DEM.

Walking Access to Public Bins on Edinburgh’s Core Paths

Network Analysis ArcGIS Pro Python Data Visualisation

This project investigated how easily walkers on Edinburgh's core path network can reach a public bin on foot. Core paths are routes identified by the Scottish government to support public access, but has the government done a sufficient job at providing bins at regular intervals?

Tools and techniques: ArcGIS Pro, Network analysis, Spatial data management, Python visualisation.

Data and methods

Sections were classified into 0-5 minutes, 5-15 minutes and 15+ minutes based on their relative walking time to the nearest public bin, assuming a walking speed of 4.8 km/h. Only bins 30 metres from the path were treated as accessible.

Results

The analysis revealed clear variation in access to public bins. Coverage was strongest in central and adjacent wards, with over 79% of core paths in Leith, Leith Walk, Forth, City Centre and Inverleith located within a five-minute walk of a bin. Less densely populated wards further out generally had poorer bin accessability. In the Pentland Hills, 90* of core paths were over 15 minutes from the nearest accessible bin.

Data credits: City of Edinburgh Council Open Spatial Data Portal: City Boundaries, Communal Bin Locations, Core Path Network.

River Almond 2D Flood Modelling (High Flow Simulation)

HEC-RAS Hydaulic Modelling ArcGIS Pro

This project simulated high-flow conditions along the River Almond in Livingston using observed discharge, a LiDAR terrain model, and surface roughness from a landcover map produced from Sentinel-2 imagery using Random Forest classification. The finished model was compared with SEPA’s published flood mapping at a 200-year recurrence interval to assess the difference between models.

Tools and techniques: HEC-RAS 2D hydraulic modelling, ArcGIS Pro, Random forest image classification, Spatial data management, Python visualisation.

Data and methods

A Sentinel-2 multispectral image was classified using the ArcGIS Pro Random Forest classifier to produce a landcover map containing four classes: water, urban, forest and fields. Manning’s roughness coefficients were assigned to each class and incorporated into a 2D HEC-RAS model.

The model terrain was derived from a LiDAR DTM. Breaklines were added to the banks and floodplains. The simulation was run using observed 15-minuite discharge measurements from the nearby Almondell gauging station.

Results

The simulation predicted flooding at several locations along the strip. Comparison with SEPA’s published 200-year flood mapping showed limited agreement, with the model predicting extensive floods across areas which are not identified to be at any risk by SEPA. No flooding was reported during this time in October 2020.

This suggests the model is overestimating inundation. This could be due to the absence of river depth in the LiDAR terrain model or errors in the surface roughness parameters.

Data credits: Scottish Environment Protection Agency: Almondell Discharge, Flood Risk Layers; Copernicus: Sentinel-2 Imagery; Scottish Remote Sensing Portal: LiDAR Digital Terrain Model.
